# Raw Experiment Archive

이 디렉터리는 프로젝트 진행 중 작성한 세부 protocol/result 문서를 보존하는 archive입니다.

**최종 결론을 보기 위해 이 파일들을 순서대로 읽을 필요는 없습니다.**

먼저:
- [../FINAL_REPORT.md](../FINAL_REPORT.md)
- [../model_evolution.md](../model_evolution.md)

를 읽으세요.

여기의 문서에는 당시 시점의:
- Next step
- TBD
- 임시 reference
- preregistered gate
- 중간 결론

이 남아 있을 수 있습니다.

이는 오류가 아니라 **당시 의사결정 과정을 보존한 기록**입니다.  
프로젝트 종료 시점의 최종 판단과 충돌할 경우 `FINAL_REPORT.md`를 우선합니다.
