> Does a TEAM-C-inspired fine-tuning recipe improve the local Qwen3-VL-8B component enough to add useful ensemble diversity?

## Ensemble experiment

Before this FT-8B addition, the best observed submission was:

- TEAM-C896: **76%**
- Permutation-8B: **19%**
- B3P3: **5%**
- Public LB: **0.95204**

A single preregistered-style conservative FT-8B diversity candidate was created by shrinking the existing best mixture to 95% while preserving its internal ratios, then assigning 5% to FT-8B:

- TEAM-C896: **72.20%**
- Permutation-8B: **18.05%**
- B3P3: **4.75%**
- FT-8B: **5.00%**

Combination method:
- weighted log probabilities over a/b/c/d candidate scores

Relative to the 0.95204 best:
- changed test argmax predictions: **9 / 6,714 = 0.13%**
- new answer distribution:
  - a: 1,708
  - b: 1,681
  - c: 1,644
  - d: 1,681

Submission:
- `ENSEMBLE_TEAM722_PERM1805_B3P3_0475_FT8B_05.csv`

Observed Public LB:
- **0.95263**

Delta vs previous best:
- **+0.00059**
- **+0.059 percentage points**

## Decision

Adopt **0.95263** as the current best observed Public LB.

Interpretation:
- FT-8B showed a small positive paired VAL-A signal.
- Adding FT-8B at only 5% changed just 9 test predictions yet improved Public LB.
- This supports FT-8B as a useful diversity component in the current ensemble.

Do **not** start a dense Public-LB weight search around 3%, 7%, 10%, etc. The value of this result is that one bounded 5% diversity hypothesis improved the existing best without large prediction churn.
